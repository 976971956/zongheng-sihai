# 纵横四海

一个使用 Godot 4 制作的手机竖屏 2D 航海 RPG。玩法依据 QQ 家园时代《纵横四海》的旧资料和实机录像重新梳理，现已完成十三卷 1–100 级离线单机篇章。

## 启动

在项目目录运行：

```bash
godot --path .
```

也可以打开 Godot，导入本目录中的 `project.godot`，然后点击右上角运行按钮。

## 浏览器直接游玩

访问 [GitHub Pages 网页版](https://976971956.github.io/zongheng-sihai/)即可开始游戏。电脑浏览器会居中显示竖屏游戏框，手机浏览器则自动适配可用高度。

网页版使用浏览器本地存储保存进度；清理该站点的浏览器数据会同时清除存档。

网页发布包会自动排除测试、开发预览图和未使用资源。中文使用由完整 Noto Sans CJK 源字体生成的游戏子集：若新增剧情文字，请先运行 `tools/build_subset_font.py` 再导出。原创音乐与音效源文件总计约 601KB，不会明显拉长首次加载。

- 交谈、到达、杀怪、买卖、强化与 Boss 等连续任务，达成后主动弹出领奖并衔接下一任务；
- 背包、补给、六部位装备、装备强化、未知道具鉴定、怪物卡构筑与套装掉落；
- 2 人队伍的 5% 攻防加成和月虎宠物协战；
- 威尼斯、拉古萨、亚历山大、马耳他、开普敦、泉州、雅典、扬州、阿姆斯特丹九港贸易，含每日行情、动态商路推荐、剧情订单、声望价格优惠、护航物资、循环商会委托与船只成长；
- 马耳他港口厨房：把柑橘、橄榄油和香料等贸易货物烹制为具有多场战斗加成的远航餐食；
- 训练场、黑帆据点、白鲸残骸三座四层副本逐层生成守卫，另有聚宝盆、妖气长安、地魔宝藏、蒂拉之剑、天魔传奇、玉历宝纱、釜底抽薪、天魔归来、天工神剪、封印迷阵十场终局远征；
- 4处世界发现物、可轮换的城市悬赏，以及从「潮汐纪事」延续到「封印迷阵」的十三卷、三十九章连续主线；

- 本地自动存档；
- 5 套原创场景/战斗循环音乐与 12 类交互、战斗、奖励音效，地图和战斗间自动过渡，支持一键静音并记住设置；
- 手机端 720×1280 竖屏界面、底部虚拟摇杆、大触控按钮、全屏战斗页和刘海安全区适配。

## 手机竖屏版

项目会根据窗口方向自动切换布局：横屏使用电脑三栏，竖屏使用“人物 / 地点 / 任务 / 背包”底部导航。手机端采用 720×1280 逻辑设计尺寸，并会根据真实设备宽高比继续扩展可用区域。

在电脑上预览手机布局：

```bash
godot --resolution 720x1280 --path .
```

Android 和 iOS 导出会沿用同一套竖屏界面；本项目已配置 iOS 导出预设。

## 操作

- 点击地面自动移动，或用左下虚拟摇杆自由移动；
- 接近 NPC、怪物或传送点后，点击右下交互按钮；
- 底部按钮可打开背包、贸易、地图和任务导航。

## 主要文件

- `scenes/world_2d.tscn`：2D 竖屏主场景；
- `scripts/world_2d.gd`：大地图、摇杆、NPC、怪物、战斗和贸易界面；
- `scripts/actor_2d.gd`：角色绘制与动画；
- `scripts/game_state.gd`：角色状态、战斗、任务、存档；
- `scripts/game_data.gd`：地点、敌人、物品和任务配置；
- `scripts/world_map_2d.gd`：地图绘制与区域覆盖。
- `tests/playability_test.gd`：不提等级、不改属性的30次正常成长压测。
- `tools/build_subset_font.py`：根据实际游戏文本重建小体积中文运行字体。
- `tools/build_audio.py`：可重复生成项目自有的小体积音乐与音效。
- `原版玩法考据与改造说明.md`：资料依据、原版逻辑与本轮改造边界。
