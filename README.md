# 纵横四海

一个使用 Godot 4 制作的手机竖屏 2D 航海 RPG。玩法依据 QQ 家园时代《纵横四海》的旧资料和实机录像重新梳理，现已完成威尼斯 1–15 级离线单机篇章。

## 启动

在项目目录运行：

```bash
godot --path .
```

也可以打开 Godot，导入本目录中的 `project.godot`，然后点击右上角运行按钮。

## 浏览器直接游玩

访问 [GitHub Pages 网页版](https://976971956.github.io/zongheng-sihai/)即可开始游戏。电脑浏览器会居中显示竖屏游戏框，手机浏览器则自动适配可用高度。

网页版使用浏览器本地存储保存进度；清理该站点的浏览器数据会同时清除存档。

## 已实现

- 失忆者在海边获救、寻找艾丽莎和威尼斯酒馆老板的原版式开局；
- 镜头跟随的威尼斯、城外、训练场与黑帆据点大地图，支持点击寻路和虚拟摇杆；
- 统一的斜俯视角色、NPC 和怪物绘制，行走、待机与战斗使用可视化动画；
- 持久化逐回合战斗：单次攻击、自动战斗、撤退、Boss 技能预告、战斗姿态、自动补给与战败回酒馆；
- 中毒、虚弱、缓慢、诅咒，以及万能药解除状态；
- 交谈、到达、杀怪、买卖、强化与 Boss 等连续任务，达成后主动弹出领奖并衔接下一任务；
- 背包、补给、六部位装备、装备强化、未知道具鉴定、卡片收藏与套装掉落；
- 2 人队伍的 5% 攻防加成和月虎宠物协战；
- 威尼斯、拉古萨、亚历山大港口贸易，含每日市场事件、价差、舱容、风险、贸易合约与船只成长；
- 两座四层副本逐层生成守卫，含楼层锁、Boss 引导和专属装备奖励；
- Lv.1–15 成长曲线，满级后经验显示 MAX；
- 本地自动存档；
- 手机端 720×1280 竖屏界面、底部虚拟摇杆、大触控按钮、全屏战斗页和刘海安全区适配。

## 手机竖屏版

项目会根据窗口方向自动切换布局：横屏使用电脑三栏，竖屏使用“人物 / 地点 / 任务 / 背包”底部导航。手机端采用 720×1280 逻辑设计尺寸，并会根据真实设备宽高比继续扩展可用区域。

在电脑上预览手机布局：

```bash
godot --resolution 720x1280 --path .
```

Android 和 iOS 导出会沿用同一套竖屏界面；本项目已配置 iOS 导出预设。

- `build/ios/DerivedData-final/Build/Products/Debug-iphoneos/SiHai.app`：已通过 Apple Development 签名的 iPhone ARM64 真机应用；

- `IOS打包与真机安装说明.md`：Xcode 签名、真机运行与 App Store/TestFlight 归档步骤。

## 操作

- 点击地面自动移动，或用左下虚拟摇杆自由移动；
- 接近 NPC、怪物或传送点后，点击右下交互按钮；
- 底部按钮可打开背包、贸易、地图和任务导航。

## 主要文件

- `scenes/world_2d.tscn`：2D 竖屏主场景；
- `scripts/world_2d.gd`：大地图、摇杆、NPC、怪物、战斗和贸易界面；
- `scripts/actor_2d.gd`：角色绘制与动画；
- `scripts/game_state.gd`：角色状态、战斗、任务、存档；
- `scripts/game_data.gd`：地点、敌人、物品和任务配置；
- `scripts/world_map_2d.gd`：地图绘制与区域覆盖。
- `原版玩法考据与改造说明.md`：资料依据、原版逻辑与本轮改造边界。
