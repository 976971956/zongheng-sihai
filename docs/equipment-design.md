# 《纵横四海：潮汐纪事》装备设计基线

## 旧版考据结论

QQ 家园旧版已经无法直接登录复核，现存资料以 2009–2015 年玩家问答和后续服攻略为主，因此以下内容按可信度使用：

- 高可信：装备部位包括手持、头戴、身穿、腰戴、脚穿和佩戴；同名系列凑齐后会显示额外套装属性。2009 年玩家问答已明确武士套有完整五件和套装加成，[2012 年套装资料](https://zhidao.baidu.com/question/448826521.html)记录了武士刀、帽、甲、腰带、鞋以及各自等级、耐久和特性。
- 高可信：成长路线不是一直换单件，而是围绕武士、哥伦布/麦哲伦、奔月与七海、地魔三套、天魔、海誓山盟、虚无等组合逐段替换。[2013 年玩家整理](https://zhidao.baidu.com/question/326913567291910245.html)和[等级路线问答](https://zhidao.baidu.com/question/487948590091477252.html)能相互印证这些套装名称与大致阶段。
- 高可信：武士套是任务和低级副本产物，前期价值包含物品掉落；30 级后进入副本套与稀有套选择。[2010 年装备问答](https://zhidao.baidu.com/question/153969441.html)提到武士套约用到 15 级、30 级转哥伦布；后续服攻略仍保留“新手套→海套/奔月→地魔→天魔→虚无”的骨架。
- 中可信：强化地点为伦敦铁匠铺贝里昂；早期强化只花银币，高阶需要龙泉水、图纸和材料，失败消耗材料但不掉级。[强化地点旧问答](https://zhidao.baidu.com/question/147192902.html)与[后续攻略汇总](https://ivjnow.com/98d30e76287d8b1e/da57c0bc2fda0ec1.html)一致，但不同运营时期的概率和等级上限可能有变化。
- 中可信：每件装备可镶嵌受部位限制的宝石，饰品偏抗性；潜水、未知道具、任务、副本、活动和打造共同构成装备来源。宝石与强化细节主要来自后续服攻略，当前版本暂不照搬付费与每日次数限制。

## 当前版本的融合规则

本项目等级上限是 100，不能直接套用旧版 140–200 级数值，因此保留结构和换装抉择，重新平衡数值：

1. 六部位保持为手持、头戴、身穿、腰部、脚穿、配饰。
2. 套装采用 2 件、4 件、整套分段激活；白鲸与终局三件套采用 2/3 件，保证每个阶段都能形成可见提升。
3. 单件仍提供基础属性，套装共鸣额外增加体力、攻击、防御、速度或寻宝率。
4. 一键推荐比较完整配装战力，会把拆掉当前套装造成的损失计算进去。
5. 强化上限为 +10：+1～+3 只需银币，+4～+7 额外消耗龙泉水，+8～+10 再需要强化图纸。单机版强化稳定成功，不加入失败等待和付费神水。
6. 装备来源继续与剧情绑定：任务奖励保证核心部件，副本 Boss 可重复掉落，未知道具负责补足前期散件，贝里昂出售珠宝和高阶锻造材料。

## 后续边界

- 宝石镶嵌需要先解决装备实例化问题；当前升级与装备以物品 ID 保存，同名装备共享强化记录，不适合直接添加多孔和随机词条。
- 若加入宝石，应先把装备迁移为独立实例，再实现红/蓝/绿/紫/橙宝石的部位限制、拆卸与存档迁移。
- 不恢复耐久度和强化失败等待。这两项在离线单机中只增加维护成本，无法产生旧版玩家交易和社交环境中的价值。
